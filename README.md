# Цифровая мастерская

Next.js + TypeScript сайт для услуг веб-разработки, интеграций, автоматизации, серверов, SEO и сопровождения.

## Запуск

```bash
npm install
npm run dev
```

## SEO

Для корректного canonical, sitemap и robots укажите домен:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.ru
```
